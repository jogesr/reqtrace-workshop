# Supportwissen wiederverwenden (Demo)

> **Synthetisch.** Fiktive, bereits gelöste Supportfälle zum fiktiven Produkt RW-100. Keine echten Kunden- oder Supportdaten.

- `tickets/` – gelöste Fälle (Symptom, Ursache, Lösung)
- `neue_anfrage.md` – eine neue Anfrage

Ziel der Demo: Ähnliche gelöste Fälle finden, einen Antwortentwurf erstellen und **Unsicherheiten sowie fehlende Angaben** sichtbar machen.
Der Entwurf wird von einer Supportperson geprüft, bevor er verschickt wird. In der Praxis: Datenschutz und Freigabe der Datenquelle vorher klären.
